# Aditya Kakde — Portfolio

Personal portfolio site. Static HTML/CSS/JS — no build step.

## Files
- `index.html` — the whole site
- `photo.jpg` — profile photo
- `resume.pdf` — downloadable résumé

## Update content
Projects, skills, patents and the architecture diagram text live in plain JS arrays
near the bottom of `index.html` (`P`, `SK`, `PAT`, `ARCH`). Edit, commit, push — the site updates in ~1 minute.
To swap the résumé, replace `resume.pdf` with a file of the same name.
